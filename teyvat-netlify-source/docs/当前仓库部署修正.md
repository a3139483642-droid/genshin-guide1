# 当前 GitHub 目录的部署修正

已核对仓库 a3139483642-droid/genshin-guide：仓库根目录只有 teyvat-netlify-source 与 teyvat-netlify-fix 两个文件夹。完整源码文件夹仍是旧版，修复文件夹没有合并进去。

1. 在 GitHub 仓库首页点击 Add file → Upload files。将本机 deliverables/teyvat-netlify-source 整个文件夹拖入，点击 Commit changes。该文件夹已合并全部修复，同名文件会更新。
2. 当前 Netlify 项目中打开 Project configuration → Developer settings → Continuous deployment → Build settings → Configure。Base directory 填 teyvat-netlify-source；Build command 填 npm run build；Publish directory 填 dist；Functions directory 填 netlify/functions。保存。
3. 进入 Deploys → Trigger deploy → Deploy project。等待新部署 Published。

不要将 Base directory 设为 teyvat-netlify-fix；它只有增量修复文件，缺少完整页面及迁移文件。

本次日志 ENOENT /opt/build/repo/package.json 由 Base directory 留空、而 package.json 位于子目录引起。修正目录后，再以实际构建日志及 /api/status 验收上线。
