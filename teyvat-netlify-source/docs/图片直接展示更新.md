# 图片直接展示更新

本次更新让上传的 PNG、JPEG、WebP 原样显示在攻略页面，支持只有图片的攻略模块。文字说明可以留空，点击图片可以打开完整原图。

## 更新现有网站

1. 解压 `teyvat-image-display-fix.zip`。
2. 将其中的文件放到 GitHub 仓库现有的同名目录，替换对应文件。解压包内直接包含 `src`、`server`、`netlify` 等目录；不要额外上传成一个独立修复文件夹。
3. 提交到 Netlify 已连接的部署分支，等待新部署显示 `Published`。
4. 刷新网站，原先已经发布的文档配图会按原图展示。此更新不修改数据库或已有攻略内容。

## 上传与发布图片

1. 管理工作台 → 导入新攻略 → 上传文件，选择 JPG、PNG 或 WebP。
2. 导入完成后直接显示原图，并自动关联到“攻略图片”模块。
3. 进入整理器，选择所属角色、填写方案名称，预览图片。
4. 保存草稿，勾选发布确认，再点“直接发布”。图片模块的文字内容可以留空。

之前出现“OCR 未配置”而失败的图片导入任务，可以在更新后点“重试解析”，处理完成后按以上流程发布，不必重新上传。

## 验证

- 20 项自动检查通过。
- 使用原生 Netlify Request/Response 包装器验证 PNG、JPEG、WebP 上传、读取和发布；返回内容与上传原图逐字节相同。
- 尚未发布的展示图片和原始资料保持私有；发布的图片模块允许访客读取。
